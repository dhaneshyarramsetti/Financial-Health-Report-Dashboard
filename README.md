# 📊 Financial Health Report Dashboard

## 📌 Overview
The Financial Health Report Dashboard is an interactive Power BI project that provides a comprehensive view of an organization's financial performance. It enables users to analyze revenue, expenses, profit, debt, and profit margin through dynamic visualizations and KPI cards.

This dashboard helps business managers and stakeholders monitor financial health, identify trends, and make data-driven decisions.

---

## 🚀 Features
- 📈 Total Revenue Analysis
- 💰 Total Profit Tracking
- 💸 Total Expenses Monitoring
- 🏦 Total Debt Overview
- 📊 Net Profit KPI
- 🎯 Profit Margin Gauge
- 📅 Monthly Revenue Trend
- 📉 Revenue vs Expenses vs Profit Comparison
- 🥧 Category-wise Financial Distribution

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)
